# 0016. Deterministic backend conflict detection for material contradictions

- Status: Accepted
- Date: 2026-10-27
- Context: AC-21 requires material contradictions to be surfaced as `UNCERTAIN`/`CONFLICTING` and never silently merged into one confident answer, and the brief requires the three-path distinctions to not depend solely on the model behaving correctly. Verification round 1 proved the model silently merges contradictions (case_11: RTO 1h vs 4h; case_14: vacation 10 vs 20 days — both returned `is_complete=True`/`confidence=HIGH` with a single merged value and an `ANSWERED` facet). Constraints forbid a second model acting as judge, external AI, and reranking; ADR 0013 already established backend validation of the model's structured output against IR-1..IR-6.
- Decision: Add a deterministic, backend-level conflict check as an extension of ADR 0013's validation layer: after generation, for each facet the model marked `ANSWERED`, the backend inspects THAT facet's cited excerpts (from local storage) for conflicting values — at minimum the numeric-contradiction class observed in the evaluation (different numbers cited for the same facet). When a conflict is detected, the backend downgrades the facet to `CONFLICTING`, forces `is_complete=false`, adds a `missing_info` entry describing the conflict (both values and both sources), and keeps both citations for traceability — mirroring how citations are backend-assembled rather than model-trusted. The facet prompt still asks the model to self-report `CONFLICTING` (defense in depth); the backend check is the guarantee. The check is conservative (only same-facet citations compared) and its heuristic limits are documented as known limitations (non-numeric or subtle conflicts remain model-dependent).
- Alternatives considered:
  - Prompt-only reinforcement — rejected because it is model-dependent; verify-1 proved the model silently merges; fails the "not solely the model" bar of the brief.
  - Second model as conflict judge — rejected because it is explicitly forbidden by the brief's constraints.
  - NLI/semantic-similarity conflict detection — rejected because it requires another model or heavy dependencies; same forbidden-judge problem.
  - Documented-limitation-only (accept the silent merges as known defects) — rejected because it weakens the explicit acceptance criterion AC-21, which the brief forbids.
  - Full entity/attribute extraction pipeline for general conflict detection — rejected because YAGNI; out of proportion for a 2.5-hour phase and unmeasured.
- Consequences: AC-21 becomes deterministic for the numeric-contradiction class (the class the eval dataset actually tests); possible false positives when legitimately different numbers coexist within a single facet's citations (mitigated by the same-facet-only comparison and documented); the evaluation must be re-run and `eval/RESULTS.md` + `eval/CALIBRATION.md` updated with the real post-fix observations; adds a small, flat validation module consistent with ADR 0013's approach.
